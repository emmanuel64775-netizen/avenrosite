Twitch Channel ID Finder

Convert a Twitch username into its underlying User ID.

Twitch Client ID & access token

Twitch requires every lookup to carry a Client ID and an access token. There's no simpler option on their end, even for a tool this small. The part that matters: it's a one-time setup, about two minutes, and this tool just works after that.

  1. Register a free app in the Twitch Developer Console, under a minute. Note your Client ID and Client Secret.
  2. Copy the command below, drop in your own Client ID and Client Secret, and run it once in a terminal (or a tool like Postman) to get your access token:
    curl -X POST 'https://id.twitch.tv/oauth2/token' -d 'client_id=YOUR_CLIENT_ID&client_secret=YOUR_CLIENT_SECRET&grant_type=client_credentials'
  3. Paste your Client ID and the access_token from that response below. Both stay in your browser only, never sent to Avenro. Once they're in, you won't need to touch this section again until a token eventually expires.
FAQ

Good to know

What is a Twitch User ID?

Every Twitch account has a permanent numeric User ID behind the username shown in your URL. Usernames can be changed, but the ID never does, which is why it's the value APIs, bots, and third-party dashboards actually key off of.

Why does this need two values instead of one?

Twitch's Helix API requires both a Client ID (identifying the app making the request) and a bearer access token (authorizing it), unlike simpler single-key APIs. It's more setup, but it's still free and still yours to control.

Do my credentials expire?

App access tokens generated this way typically last around 60 days. When a lookup starts failing, just re-run the curl command above to generate a fresh token.

Is this free to use?

Yes. Twitch's Helix API is free for this kind of lookup. You're just using your own developer credentials directly from your browser.
